FRB公表値／FREDの日次系列。ドル指数は広範ドル指数（DTWEXBGS）で、ICEのDXYとは異なります。米10年実質金利はTIPS利回り（DFII10）。因果関係や金の値動きを断定する指標ではありません。

実装内容・計算方法・更新のしくみ

金先物騰落率は前取引日・5取引日前・21取引日前の終値比。SPDR保有増減は同じファンド内の数量差。ポジションはCFTC週次建玉差、中国の12か月は連続13回の月末残高差です。参照日を各欄に表示します。

価格の現在値は画面表示中60秒間隔。追加系列はGitHub Actionsで毎日7:30 JSTに取得を試みます。取得失敗時は出典・基準日のある前回値を残し、失敗状態を表示。欠測はゼロに置き換えません。中国以外の実名機関の固定資料は自動更新対象外です。

計算は境界条件・実データとの照合を行い、公開後にPC・スマホ幅・期間切替・絞り込みを検証しています。
