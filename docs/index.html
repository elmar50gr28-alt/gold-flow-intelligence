週次のポジション統計

COTは通常、火曜日時点の建玉を金曜日に公表する統計です。休日や公表遅延で日程が変わります。リアルタイム金価格は表示していません。

ネットはロング − ショート

プラスは買い越し、マイナスは売り越し。前週比はポジションの変化です。現金の流入・流出や将来の価格を直接示すものではありません。

公式データを無料で

対象はCOMEX GOLD（088691）、Disaggregated Futures Only。先物のみで、オプション合算ではありません。1枚は100トロイオンスです。

出典：CFTC公式データ · COTレポート案内

GitHub Actionsで毎日取得を試みます。公表元に新しい統計がない場合、基準日は変わりません。オフライン時は保存済みの画面と統計を表示します。投資判断の参考情報であり、売買を推奨するものではありません。
